# Flexo Spaces – Smart Co-Working Space Management Platform

🌐 **Live Project:** https://flexo-spaces.netlify.app/

📂 **GitHub Repository:** https://github.com/bottemeghana-hash/flexo-spaces

## About the Project

Flexo Spaces is a smart co-working space management and booking platform designed to help freelancers, startups, professionals, and businesses discover and reserve premium workspaces.

Users can explore workspace options, compare amenities and pricing, and manage their bookings through an online platform.

## Key Features

- User registration and login
- Browse premium workspaces
- Search and filter workspaces
- Workspace details and amenities
- Online workspace booking
- Booking status management
- Saved and favourite workspaces
- User dashboard
- Admin dashboard
- Workspace and booking management

## How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/bottemeghana-hash/flexo-spaces.git
```

### 2. Start the backend

```bash
cd flexo-spaces/backend
npm install
npm run dev
```

Configure your backend environment variables in a private `.env` file.

### 3. Start the frontend

Open another terminal:

```bash
cd flexo-spaces/frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal.
